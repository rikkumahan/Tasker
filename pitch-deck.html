06 — Tech Stack
Engineered
for speed,
built for
privacy.

Every decision optimized for zero-latency extraction and zero-trust data handling.

∎ Privacy · Non-Negotiable
We never store your raw emails. Ever.
Emails are processed in-memory, PII stripped in 3 stages (regex → WASM → rehydration), then discarded. Only extracted tasks and metadata are persisted. Your inbox content is yours alone.
Frontend
React 19
+ Vite
Static SPA · @supabase/supabase-js
Real-time dashboard with urgency-colored task cards and live sync indicators.
Backend
Supabase
Edge Fn
Deno/TypeScript · PostgreSQL + RLS
Serverless functions handle ingestion, extraction, and delivery. No separate server.
AI Brain
Groq
Llama 3
llama-3.3-70b-versatile · ~200ms inference
State-of-the-art open model on Groq's LPU — fast enough for real-time email→task extraction.
Email Layer
Gmail
API
Pub/Sub webhooks · OAuth 2.0
Push-based — tasks appear seconds after email arrives, not on a polling schedule.
Intelligence

RAG

Data Layer

+ RLS
